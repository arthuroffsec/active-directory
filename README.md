# Implementação de Active Directory — Windows Server 2016
 
Projeto de laboratório prático de infraestrutura, com a instalação e configuração de um **Active Directory Domain Services (AD DS)** em **Windows Server 2016**, incluindo a criação de domínio, estruturação de Unidades Organizacionais (OUs), criação de usuários e grupos de segurança, simulando o gerenciamento centralizado de identidades de uma empresa.
 
##  Sobre o projeto
 
Este repositório documenta a construção de um ambiente de diretório corporativo do zero: desde a instalação do papel (role) AD DS no servidor, passando pela promoção do servidor a controlador de domínio, até a organização lógica de usuários por departamento através de OUs e grupos de segurança.
 
O domínio criado foi **arthur.local**, com o servidor atuando também como **DNS** interno (instalado automaticamente durante a promoção a controlador de domínio) e **Catálogo Global (GC)**.
